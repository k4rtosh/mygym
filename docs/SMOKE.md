# Smoke checklist — MyGym

Прогон **перед каждым релизом** (web и/или APK). Цель: поведение как у платного приложения — без сюрпризов в базовых сценариях.

Версия чеклиста соответствует релизу приложения (`version.json`).

## 0. Перед стартом (раз в окружение)

- [ ] В Supabase применены миграции:
  - `supabase/migrations/20260727_body_metrics.sql`
  - `supabase/migrations/20260804_coach_goal.sql`
  - `supabase/migrations/20260804_coach_inbox.sql` ← без неё «Прочитано» в коуче падает
- [ ] После SQL: в редакторе выполнить `notify pgrst, 'reload schema';` (или Restart проекта)
- [ ] Web: hard refresh / Профиль → «Обновить приложение»
- [ ] APK: свежая сборка с тем же `version.json`

## 1. Auth

- [ ] Регистрация / вход (email)
- [ ] Выход → снова вход
- [ ] Демо-вход (`test`/`test` или кнопка) → полоска DEMO → выход

## 2. Тренировка

- [ ] Главная → «Начать тренировку»
- [ ] Список шаблонов: длинные имена не ломают счётчик; кнопка «Начать» не вылезает за экран
- [ ] Старт из шаблона → подходы → finish
- [ ] Пустая тренировка → добавить упражнение → finish
- [ ] Убить приложение mid-workout → resume / discard

## 3. Шаблоны и календарь

- [ ] Создать / переименовать / DnD порядка / сохранить
- [ ] План на день → факт / пропуск виден в календаре

## 4. Коуч

- [ ] Задать цель (intent + фокус search-select)
- [ ] Карточки ≤ ~7 (brief + лимит)
- [ ] «Прочитано» на карточке и «Прочитано» в баре — без ошибки
- [ ] Режим «Простой» → «Вернулся в зал» → карточка возврата
- [ ] Микроплан → «Собрать шаблон»

## 5. Прогресс и каталог

- [ ] График упражнения
- [ ] Собственный вес
- [ ] База упражнений → «i» → модалка по центру (не прилипает к статус-бару)

## 6. Профиль / данные

- [ ] Экспорт JSON
- [ ] Импорт (сессии + вес + цель коуча)
- [ ] Версия в профиле = `version.json`

## 7. Обновление / PWA

- [ ] Смена версии → модалка обновления (web)
- [ ] Offline: shell открывается (после хотя бы одного визита online)

---

## Быстрый минимальный прогон (~5 мин)

1. Демо → коуч «Прочитано»  
2. Шаблон → короткая тренировка → finish  
3. Каталог → модалка упражнения  
4. Новая тренировка: вёрстка кнопок  
5. Экспорт  

Если что-то красное — не бампать `version.json` / не мержить релизный PR.
